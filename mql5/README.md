# PumpingBotFollower EA (MT5)

Users run **only Exness MetaTrader 5**. This EA copies master trades.

1. Compile in MetaEditor (F7) or attach `.mq5` (MT5 auto-compiles).
2. Allow WebRequest URL = your Railway app.
3. Set `InpToken` from app → PC Setup.

Server APIs: `/ea/hello`, `/ea/poll`, `/ea/ack`, `/ea/download`
