PumpingBot Setup — Windows
==========================

1) Pehle Exness MetaTrader 5 install + apna account login karo.
2) App (PumpingBot) pe login → MT5 page pe account SAVE.
3) App → PC Setup → "Copy EA Token".
4) Yeh folder mein PumpingBotSetup.bat DOUBLE-CLICK.
5) Jab pooche, token PASTE karo.
6) Installer EA + config + WebRequest URL khud laga dega.
7) MT5 mein:
   - AutoTrading ON
   - Navigator (Ctrl+N) → Experts → PumpingBotFollower → chart pe DRAG → OK

Rozana baad mein: sirf MT5 open + login + AutoTrading ON.
